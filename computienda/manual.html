Manual del Usuario & Guía de Configuración

Bienvenido al centro de aprendizaje oficial de Computienda POS. Aquí aprenderás a instalar, configurar periféricos de cobro y dominar las operaciones de venta diaria en tu establecimiento.

01

Requisitos del Sistema

Computienda POS es un sistema optimizado de bajo consumo de recursos que puede operar en computadoras modernas o equipos de cómputo reciclados para mostrador:

Requisitos Mínimos

Sistema Operativo: Windows 10 (32 o 64 bits).

Procesador: Intel Core i3 / AMD Athlon 2.0 GHz.

Memoria RAM: 4 GB.

Espacio en Disco: 500 MB libres para base de datos local.

Recomendado por Compubyte

Sistema Operativo: Windows 10 / 11 Pro 64 bits.

Procesador: Intel Core i5 o superior.

Memoria RAM: 8 GB.

Almacenamiento: Unidad SSD para apertura instantánea de ventas.

Instalación Paso a Paso

  1. Descarga del instalador: Ejecuta el archivo ComputiendaPOS_Setup_v4.5.exe provisto por el equipo técnico de Compubyte.
  2. Permisos de Administrador: Haz clic derecho y selecciona "Ejecutar como administrador" para permitir la correcta creación de la base de datos local.
  3. Carpeta de instalación: Se recomienda mantener la ruta predeterminada C:\ComputiendaPOS\.
  4. Acceso Directo: El asistente colocará automáticamente un icono en tu Escritorio listo para iniciar.
ℹ

¿Tu instalación incluye kit físico?

Si adquiriste la póliza de puesta a punto de Compubyte, nuestros ingenieros configuran de forma remota o presencial los controladores de la impresora térmica y el puerto del cajón.

Primer Inicio y Credenciales por Defecto

Al abrir el programa por primera vez, verás la pantalla de inicio de sesión de seguridad. Utiliza los accesos de fábrica de nivel Administrador:

Usuario: admin

Contraseña: 1234

⚠️

Cambio obligatorio de contraseña

Por seguridad operativa de tu negocio, dirígete al menú Configuración > Usuarios y actualiza la clave del administrador para evitar modificaciones no autorizadas por parte de empleados.

02

Datos del Establecimiento

En la pestaña Ajustes > Empresa completa el nombre comercial, RFC/NIT, dirección y mensaje al pie de ticket (ejemplo: "¡Gracias por su compra! Cambios solo con este ticket").

Captura de Pantalla: Formulario de Datos de Empresa y Logotipo de Ticket

Menú: Ajustes > Generales > Ticket de Venta

Impresora Térmica y Ticket

Computienda envía comandos de impresión en formato ESC/POS directo. Sigue estos pasos para asociar tu impresora:

  • Selecciona el ancho del papel térmico: 58 mm (ticket angosto) u 80 mm (estándar con corte automático).
  • En la lista desplegable de impresoras de Windows, selecciona tu dispositivo (ej. POS-80, Epson TM-T20).
  • Marca la casilla "Abrir cajón al cobrar" si tu cajón está conectado mediante cable telefónico RJ11 a la impresora.
  • Presiona el botón "Imprimir Ticket de Prueba" para validar nitidez y alineación.
03

Apertura de Turno (Fondo de Caja)

Al iniciar el día laboral, el cajero debe declarar el monto inicial en monedas y billetes para dar cambio:

  1. Ingresa a la pantalla principal de Caja.
  2. Aparecerá la ventana modal: "Declarar Fondo Inicial".
  3. Digita la cantidad (ej. $500.00 MXN) y presiona Aceptar. El cajón se abrirá para guardar el dinero.

Cómo Realizar una Venta y Cobro Rápido

La pantalla de cobro está diseñada para operarse 100% con teclado o con pantalla táctil:

Escanear código de barras o digitar clave Enter
Buscar producto por nombre descriptivo F10
Cobrar y abrir ventana de pago F12

Cierre de Caja (Corte X y Corte Z)

Diferencias clave entre ambos procedimientos de cierre:

Corte X (Informativo Parcial)

Muestra el acumulado de ventas hasta el momento sin cerrar la caja ni reiniciar los contadores. Ideal para cambio de turno a mediodía.

Corte Z (Cierre Definitivo)

Finaliza la jornada, imprime el resumen consolidado de formas de pago, envía copia por correo al dueño y resetea el turno para el día siguiente.

04

Alta de Nuevos Productos

Ve a Inventario > Catálogo de Productos y presiona Nuevo (F1). Los campos clave son:

  • Código de Barras: Escanéalo directamente del empaque del producto o deja en blanco para que el sistema genere un código interno de 4 dígitos.
  • Descripción: Nombre legible para el ticket (ej. "Detergente Líquido 1L").
  • Costo y Precio: Ingresa el costo que te da el proveedor y el precio público. El sistema calculará tu margen de ganancia en porcentaje de forma automática.
  • Existencia y Stock Mínimo: Si fijas stock mínimo en 5, el sistema te avisará con color ámbar cuando queden 5 piezas o menos.
05

Preguntas Frecuentes (FAQ)

¿Qué pasa si se corta la luz o el Internet? ▼

Computienda guarda cada venta en una base de datos local instantánea. No perderás ninguna transacción ni ventas realizadas. Al volver la energía eléctrica, el sistema reanudará exactamente donde te quedaste.

¿Cómo hago una copia de seguridad (Backup)? ▼

Ve a Ajustes > Mantenimiento > Crear Respaldo. Se generará un archivo comprimido que puedes guardar en una memoria USB o disco duro externo para mayor protección de tus catálogos y ventas.

¿Se pueden conectar 2 computadoras a la misma base de datos? ▼

Sí. Puedes configurar un equipo como Servidor Principal y otras máquinas como Cajas Esclavas conectadas mediante la red local (WiFi o cable Ethernet).
